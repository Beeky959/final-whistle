⚽ Final Whistle Reaction

A fast-paced football reaction game built using HTML, CSS, and JavaScript. Test your reaction speed in a stadium-style environment with immersive football visuals, live score tracking, reaction timers, animations, and responsive gameplay.

🔥 Features
- Stadium-themed football UI
- Realistic football visuals
- Reaction time tracking
- GOAL and MISS animations
- Best reaction score system
- Responsive mobile and desktop design
- Beginner-friendly clean code

🛠️ Built With
- HTML5
- CSS3
- JavaScript
